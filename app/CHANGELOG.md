# Changelog

The Updates tab shows this file. Each release starts with a second-level heading, `<version> - <date>`,
newest first.

## 1.1.1 - 2026-10-25

Reading the game audio no longer fails on a stray file in the Helldivers 2 data folder. The error said "unpack requires a buffer of … bytes".

## 1.1.0 - 2026-10-25

### The Soundtrack tab

A new tab sets how each piece of music plays in a mission: in the original order, as one song cut across the segments, as a playlist of whole songs, or silent. Whole fights can be heard before building.

### Other changes

- Audiodiver Utils is Repatch and Combine Mods on their own, as a 27 MB portable window and a command line that scripts and mod managers can call.
- Audio files copied in Explorer paste into the selected slots with Ctrl+V.
- A tick on each slot selects it, and the selected slots can take one file or several at once.
- Search slots finds slots by name, label, note, file name or id, in every piece of music and sound set.
- The Index search also finds music by slot labels, and a pasted id opens at the slot.
- Make-Up Gain goes from −96 to +96 dB, dragged or typed, with one slider for several slots.
- Slots show the stream id, the id other audio tools use.
- The toolbar above the slots is a row of icons, with Play through as two round buttons at the start.
- Two buttons at the end of the toolbar hide or show the header and the waveforms.
- The header above the slots is shorter, with the facts side by side.
- Audio, Soundtrack and Text can be hidden, in Settings or for one project.
- Build sits apart from the project tabs and shows only while a project is open.
- Along a top or bottom bar, the tabs share one width, and a longer name widens only that tab.
- Home stays the same with a project open and lists recent projects under Open project.
- With no project open, the Project tab lists recent projects, and a new project shows where to start.
- The Wiki has a page of frequently asked questions, and headings that stand out by level.
- Ctrl+F in the Wiki finds and marks words on the page, and a page opened from the search marks the words searched for.
- Installed mods and Combine Mods also read the library of a second mod manager.
- Combine Mods shows setting values with units.
- The app and the Wiki say "mod manager" instead of naming one, and builds work with any manager that imports the usual manifest ZIPs.
- Shared with lists the other places by where they are, with unnamed music folded.
- An item description folds behind the ⓘ after the title.
- Dark or Light can follow the system theme, Reset to Default puts the theme back, and Reset Key Binds asks first.
- About has a Ko-fi button and names the source of the news ticker on Home.
- About and the Updates tab show the version once.
- Tooltips, notes and ? links across the app say what things are for, and the wording is plainer everywhere.
- A chosen option in a row of choices is no longer bold, so the row keeps one width.
- Six music clips had a label from somewhere else, such as Loadout #13 named "Mission End - Stats Screen".
- The tip on Raise the version after each build was wrong. The version only names the ZIP, and the mod id decides updates.
- A line in the Wiki no longer ends on an opening bracket.
- The ⓘ and the Replaced status sit level with the item title.
- The How Audiodiver works page pointed to the wrong next page.
- The Library says "never heard" as the slot rows do, and the Text tab marks changed lines as Changed.
