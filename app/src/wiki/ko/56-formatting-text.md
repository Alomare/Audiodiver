게임은 태그로 텍스트에 서식을 적용합니다. 여는 태그는 단어 앞에, 닫는 태그는 단어 뒤에 옵니다. 예를 들어 `<c=FFFFE900>ARMORED ENEMIES</c>`는 *ARMORED ENEMIES*를 슈퍼지구 노란색으로 표시합니다. [텍스트](app:text) 탭의 **새 텍스트** 위에 있는 바가 태그를 써 주며, 직접 입력할 수도 있습니다. **미리 보기**는 작업하는 동안 결과를 보여 줍니다.

아래의 각 예는 왼쪽에 입력한 줄을, 오른쪽에 표시되는 모습을 보여 줍니다.

## 서식 적용 {#applying-a-format}

1. **새 텍스트**에서 단어를 선택합니다.
2. 서식에 색상이나 크기가 있으면 먼저 설정합니다.
3. 버튼을 누릅니다.

선택한 단어 앞뒤에 태그가 들어갑니다. 단어는 선택된 채로 남으므로, 다른 버튼을 누르면 두 번째 서식이 추가됩니다. 아무것도 선택하지 않으면 버튼이 자막 타이밍 뒤의 줄 전체에 서식을 적용합니다.

태그는 중첩할 수 있습니다. 닫을 때는 역순으로 닫으세요.

```game-text
Use the <c=FFFFE900><i=1>Hellbomb</i></c> on the nest.
```

**서식 지우기**는 줄에서 모든 색상, 크기, 스타일 태그를 제거하고, 단어와 타이밍은 유지합니다. 아래에서 설명하는 게임이 채우는 색상도 제거합니다. 그럴 때는 편집기가 경고하며, {key:undo}로 되돌릴 수 있습니다.

## 색상 {#colour}

**색상**은 단어의 색을 바꿉니다. 견본으로 색을 고르거나 옆 상자에 16진수 코드를 입력한 뒤 **색상**을 누르세요.

색상 코드는 16진수 8자리입니다. 앞의 두 자리는 불투명도(`FF`는 완전히 불투명)를, 나머지는 빨강, 초록, 파랑을 정합니다. Audiodiver는 불투명도에 항상 `FF`를 씁니다. 단어를 반투명하게 하려면 더 낮은 값을 직접 입력하세요. 예를 들어 `80`은 반투명입니다.

```game-text
Pick up and use <c=FFFFE900>EXPENDABLE ANTI-TANK</c> against <c=FFFFE900>ARMORED ENEMIES</c>.
```

```game-text
<c=FFFF0000>Danger close.</c> Clear the area.
```

```game-text
<c=80FFFFFF>Barely there.</c>
```

게임에서 가장 많이 쓰는 색상은 다음과 같습니다.

| 코드 | 색상 | 줄 수 |
|---|---|---|
| `FFFFE900` | 슈퍼지구 노란색. 팁의 핵심 단어에 쓰입니다 | 166 |
| `FF336666` | 어두운 청록색 | 13 |
| `FF66cc99` | 연한 초록색 | 5 |
| `FFFF0000` | 빨간색 | 4 |

## 크기 {#size}

**크기**는 단어를 크거나 작게 만듭니다. 숫자 상자에서 10~60 사이의 크기를 정한 뒤 **크기**를 누르세요. 보통 크기는 20입니다.

```game-text
<s=30>FOR SUPER EARTH!</s>
```

```game-text
Mission complete. <s=14>Mostly.</s>
```

> [!NOTE]
> 게임의 줄 중에는 크기를 쓰는 줄이 없지만, 채팅은 씁니다. 자막이나 메뉴에서 크기가 어떻게 보일지는 게임이 정하므로, 모드를 공유하기 전에 게임에서 확인하세요.

## 강조 {#emphasis}

**강조**는 팁과 브리핑이 설명하는 용어에 쓰는 스타일인 `<i=1>`을 씁니다. 미리 보기에서는 기울임꼴로 표시됩니다. 게임에서는 강조 스타일로 나타납니다.

```game-text
Welcome to the <i=1>Galactic Map</i>. Select <i=1>Missions</i> to play.
```

다른 스타일은 바에 없습니다. 게임은 권고 사항의 제목에 `<i=3>`을, 타이머의 숫자 사이에 `<i=2>`를 씁니다. 직접 입력하세요.

```game-text
<i=3>STRATEGIC ADVISORY</i>
The Automaton <i=1>Jet Brigade</i> has been spotted.
```

## 타이밍(자막) {#timing-subtitles}

자막은 타이밍 표시 `{start->end}`로 시작합니다. 표시는 그 뒤의 문구가 대사 시작부터 몇 초에 나타나고 사라질지 정합니다. 긴 자막에는 텍스트 조각마다 하나씩 표시가 여러 개 있습니다. **타이밍**을 누르면 커서 위치에 `{0.00->2.00}`이 추가되며, 그다음 시간을 입력하세요.

```game-text
{0.00->1.85}Reinforcements inbound!
```

```game-text
{0.00->2.40}Stratagem coming in hot.
{2.40->4.10}Clear the landing zone!
```

대사의 새 오디오 길이가 다르면 자막 시간을 그에 맞게 바꾸세요. 라이브러리는 대사의 길이를 파형 위에 표시하며, 줄의 **자막** 링크는 여기서 자막을 엽니다.

## 줄 바꿈 {#line-breaks}

**새 텍스트**에서 Enter를 누르면 새 줄이 시작됩니다. 게임의 긴 텍스트는 줄 바꿈을 쓰며(440줄), 일부 긴 자막도 줄마다 텍스트 조각 하나씩 줄 바꿈을 씁니다.

## 게임이 채우는 부분 {#parts-the-game-fills-in}

게임은 줄을 표시할 때 일부 부분을 채웁니다. 이 부분은 바꾸지 말고, 문구를 고칠 때 단어와 함께 옮기세요.

- `#NAME`이나 `#COUNT`처럼 **`#` 뒤의 대문자 단어**는 플레이어 이름이나 숫자가 됩니다. 미리 보기에서는 상자로 표시됩니다.
- `<c=#PLAYER_COLOR>`처럼 **코드 대신 이름이 있는 색상**은 플레이어의 색처럼 게임이 고릅니다. 미리 보기에서는 이 태그가 색을 입히는 단어에 밑줄이 그어집니다.

```game-text
<c=#PLAYER_COLOR>#NAME</c> DIED
```

```game-text
<c=#PLAYER_COLOR>#NAME</c> gave their life for <c=FFFFE900>Super Earth</c>
```

줄에서 이런 부분이 빠지면 편집기가 경고합니다.
