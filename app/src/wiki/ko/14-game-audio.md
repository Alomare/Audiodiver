Helldivers 2는 여러 게임이 쓰는 오디오 엔진인 **Wwise**로 오디오를 재생합니다. Wwise에는 노래나 이름 붙은 파일이라는 개념이 없습니다. 클립을 컨테이너에 저장하고, 모든 것에 번호를 붙이며, 다음에 어떤 클립을 재생할지 플레이 중에 정합니다. Audiodiver는 이 구조를 플레이어가 알아볼 수 있는 대상으로 되돌리며, 이 페이지의 용어는 화면에 표시되는 용어입니다.

## 오디오가 저장되는 곳 {#where-the-audio-is-stored}

큰 것부터 작은 것 순서입니다.

1. **아카이브**는 게임의 `data` 폴더에 있는 파일 하나로, `2e24ba9dd702da24`처럼 16자 코드로 된 이름이 붙습니다. 아카이브에는 보통 무기, 진영의 음악, 한 언어의 음성처럼 한 가지 대상의 오디오가 들어 있습니다. **모든 아카이브**에 아카이브가 나열됩니다.
2. **뱅크**는 아카이브 안의 Wwise 사운드 뱅크입니다. 클립과 그 클립을 재생하는 **사운드**가 들어 있습니다. 가운데 패널 위쪽의 *아카이브 …에 있음* 줄에 아카이브와 뱅크가 함께 표시됩니다.
3. **사운드**는 *오토캐넌 사격*이나 *"재장전!"*처럼 게임이 실행할 수 있는 것 하나입니다. 사운드에는 **테이크**가 하나 이상 있으며, 실행될 때마다 그중 하나를 재생합니다.
4. **테이크**는 사운드의 녹음 하나입니다. 소총 사격에는 테이크가 여러 개 있으며, 게임이 무작위로 하나를 골라 같은 소리가 두 번 나지 않게 합니다. 교체로 바뀌는 클립이 바로 테이크입니다.

음악이나 대사처럼 긴 오디오는 대개 **스트리밍**됩니다. 즉, 클립이 아카이브 안에서 뱅크 옆에 저장됩니다. 어느 경우든 Audiodiver가 클립을 찾습니다.

## 많은 것이 "시퀀스 3"이나 "테이크 2"로 불리는 이유 {#why-many-things-are-called-sequence-3-or-take-2}

게임 파일에는 번호만 있고 이름이 없습니다. Audiodiver의 이름은 커뮤니티 문서([정보 ▸ 크레딧](app:about)에 나열)와 Audiodiver가 알아낼 수 있는 정보에서 옵니다.

- 이름이 없는 시퀀스는 뱅크 순서대로 **시퀀스 1**, **시퀀스 2** 등으로 불립니다. 무엇인지 알려면 들어 보세요. 시퀀스는 재생될 때마다 게임이 하나를 고르는 테이크 묶음입니다.
- 이름 없는 시퀀스의 테이크는 **테이크 1**, **테이크 2** 등으로 불립니다. 대사처럼 받아쓴 테이크에는 그 내용이 이름으로 붙습니다.
- 이름이 없는 사운드 세트나 아카이브는 아카이브 코드로 이름이 붙고 *아직 이름 없음*으로 표시됩니다.

예를 들어 "시퀀스 4 › 테이크 2"는 뱅크에서 네 번째 시퀀스의 두 번째 녹음입니다. 시퀀스를 교체하려면 모든 테이크에 새 오디오를 넣으세요. 그렇지 않으면 게임이 가끔 원본을 고릅니다.

## 기타 오디오와 게임 파일에 오디오 없음 {#other-audio-and-no-audio-in-the-game-files}

사운드 세트의 끝, 이름이나 번호가 붙은 사운드 뒤에 그룹이 두 개 나타날 수 있습니다.

- **기타 오디오**에는 뱅크가 저장하거나 이름을 가지고 있지만, 그 뱅크의 어떤 사운드도 재생하지 않는 클립이 들어 있습니다. 보통 다른 뱅크의 사운드가 재생합니다. 다른 클립처럼 재생하고 교체할 수 있지만, 무엇에 쓰이는지에 대한 정보는 없습니다.
- **게임 파일에 오디오 없음**에는 뱅크 데이터에 이름은 있지만, 설치된 게임 파일에는 없는 클립이 들어 있습니다. 삭제된 콘텐츠이거나 설치되지 않은 게임 부분입니다. ▶ 버튼이 비활성화되며, 채우기는 이 클립을 건너뜁니다.

## 음악의 구성 {#how-music-is-put-together}

Helldivers 2의 음악은 상황에 따라 바뀌도록 만들어져 있습니다. Audiodiver는 음악에 다음 용어를 씁니다.

- **큐**는 세그먼트의 재생 목록으로, 게임 데이터가 정의하는 곡 하나입니다. 슬롯의 **+큐 3개** 태그는 같은 클립이 다른 곡 세 개에서도 재생된다는 뜻입니다.
- **곡**은 *장비구성 선택*처럼 색인에 나열되는 것입니다. 큐 하나이거나, 함께 묶이는 큐 여러 개입니다.
- **파트**는 곡의 큐 하나이며, 탭으로 표시됩니다(트랜지션과 스팅어는 목록의 줄로 표시). 곡에는 생물군계별, 강도별, 또는 음성의 언어별로 파트가 있을 수 있습니다. 파트마다 슬롯이 따로 있습니다.
- **세그먼트**는 한 단위로 재생되는 음악 구간으로, **Entry** 지점과 **Exit** 지점이 있습니다. 다음 세그먼트는 Exit에서 시작하며, 현재 세그먼트의 끝부분이 그 위에 겹쳐 울립니다.
- **레이어**(스템)는 세그먼트가 동시에 재생하는 여러 클립 중 하나입니다. 레이어마다 슬롯이 따로 있습니다.
- **슬롯**은 클립이 재생되는 한 자리로, 사운드의 테이크나 세그먼트의 레이어입니다. 오디오는 슬롯 하나씩, 슬롯마다 파일 하나로 교체합니다.
- **변형**은 생물군계 같은 조건에서만 재생되는 슬롯입니다. 행에 조건이 표시됩니다.
- **트랜지션**(↝)은 두 곡 사이에 재생되는 짧은 곡입니다. **스팅어**(✦)는 음악 위에 겹쳐 재생되는 짧은 곡입니다.

자세한 내용은 [게임이 음악을 재생하는 방식](wiki:how-the-game-plays-music)에 있습니다.

## ID {#ids}

모든 클립, 사운드, 뱅크, 큐에는 번호가 있으며, 게임 파일은 이 번호만 씁니다. 메모나 다른 도구의 ID를 검색 상자에 붙여 넣으면 어디에 있는지 찾을 수 있습니다. 세부 정보 위쪽에 슬롯의 **스트림 ID**가, 오디오가 뱅크 안에만 있으면 **소스 ID**(클립 ID)가 표시됩니다. 게임 업데이트로 ID가 바뀌어도 프로젝트는 유효합니다.

## 용어집 {#glossary}

| 용어 | 의미 |
|---|---|
| 아카이브 | 게임의 `data` 폴더에 있는 파일. 뱅크와 스트리밍 클립이 들어 있습니다. |
| 할당 | 슬롯에 지정한 파일 또는 무음. |
| 뱅크 | 클립과 그 클립을 재생하는 사운드가 든 Wwise 사운드 뱅크. |
| 분류, 섹션 | 색인이 대상을 분류하는 방식. 예: 무기 ▸ 지원 무기. |
| 큐 | 세그먼트의 재생 목록. 게임 데이터가 정의하는 곡 하나. |
| Entry, Exit | 세그먼트의 큐 포인트. Entry는 세그먼트가 시작된 것으로 치는 지점, Exit는 다음 세그먼트가 시작되는 지점입니다. |
| 채우기 | 여러 파일을 한 번에 재생 순서대로 슬롯에 할당하는 것. |
| 그룹 | 사운드와 그 사운드가 고르는 테이크. 펼칠 수 있는 한 줄로 표시됩니다. |
| 색인 | 이름이 있는 모든 것을 분류한 라이브러리의 목록. |
| 레이어, 스템 | 세그먼트가 동시에 재생하는 클립. |
| 새 오디오 | 슬롯의 원본을 교체하는 파일. |
| 원본 | 슬롯에 있는 게임의 오디오. |
| 파트 | 곡의 큐 하나 또는 음성의 언어 하나. 탭으로 표시됩니다. |
| 곡 | 플레이어가 알아보는 음악. 큐 하나 이상으로 이루어집니다. |
| 전체 재생 | 게임과 같은 세그먼트 간 넘김으로 곡 전체를 재생하는 것. |
| 프로젝트 | 모드가 작업하는 대상과 할당을 기록하는 `.audi` 파일. |
| 교체됨 | 원본 대신 새 오디오나 무음을 재생하는 슬롯. |
| 세그먼트 | 한 단위로 재생되는 음악 구간. |
| 무음, 건너뛰기 | 슬롯을 아무것도 없는 것으로 교체하는 것. 건너뛰기는 트랜지션에 이것을 적용해 게임이 바로 넘어가게 합니다. |
| 슬롯 | 게임 클립이 재생되는 한 자리. |
| 사운드 | 게임이 실행하는 것. 실행될 때마다 테이크 하나를 재생합니다. |
| 사운드 세트 | 무기, 적, 음성처럼 한 대상의 사운드. |
| 소스 ID | 게임 파일에서 클립의 번호. |
| 스팅어 | 음악 위에 겹쳐 재생되는 짧은 악구. |
| 스트림 | 뱅크 밖, 뱅크 옆에 저장된 클립. |
| 스트림 ID | 스트림 파일의 64비트 번호. |
| 테이크 | 사운드의 녹음 하나. 게임이 무작위로 하나를 고릅니다. |
| 트랜지션 | 두 곡 사이에 재생되는 짧은 곡. |
| 변형 | 조건에서만 재생되는 슬롯. |
| Wwise | 게임이 쓰는 오디오 엔진. |
