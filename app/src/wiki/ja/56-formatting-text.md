ゲームは、タグでテキストに書式を付けます。開始タグは語句の前に、終了タグは語句の後に付けます。たとえば、`<c=FFFFE900>ARMORED ENEMIES</c>`は、*ARMORED ENEMIES*をスーパーアースイエローで表示します。[テキスト](app:text)タブの**新しいテキスト**の上にあるバーがタグを書き込みますが、手入力もできます。**プレビュー**には、作業中の結果が表示されます。

以下の例では、左が入力したとおりの行、右が表示される行です。

## 書式を適用する {#applying-a-format}

1. **新しいテキスト**で語句を選択します。
2. 書式に色やサイズがある場合は、先に設定します。
3. ボタンを押します。

タグは選択した語句を囲みます。語句は選択されたままなので、2つ目のボタンを押すと2つ目の書式が加わります。何も選択していない場合、ボタンは、字幕のタイミングの後ろで、行全体に書式を付けます。

タグは入れ子にできます。閉じるときは逆の順にします。

```game-text
Use the <c=FFFFE900><i=1>Hellbomb</i></c> on the nest.
```

**書式をクリア**は、行からすべての色、サイズ、スタイルのタグを削除し、語句とタイミングは残します。後述の、ゲームが埋め込む色も一緒に削除されます。そのときはエディターが警告し、{key:undo}で元に戻せます。

## 色 {#colour}

**色**は、語句の色を変更します。スウォッチで色を選ぶか、隣のボックスに16進数のコードを入力してから、**色**を押します。

色コードは16進数8桁です。最初の2桁が不透明度（`FF`は完全な不透明）で、残りが赤、緑、青を設定します。Audiodiverは、不透明度に常に`FF`を書き込みます。語句を半透明にするには、手で小さい値を入力してください。たとえば、`80`は半分の透明度です。

```game-text
Pick up and use <c=FFFFE900>EXPENDABLE ANTI-TANK</c> against <c=FFFFE900>ARMORED ENEMIES</c>.
```

```game-text
<c=FFFF0000>Danger close.</c> Clear the area.
```

```game-text
<c=80FFFFFF>Barely there.</c>
```

ゲームでよく使われる色は、次のとおりです。

| コード | 色 | 行数 |
|---|---|---|
| `FFFFE900` | スーパーアースイエロー。ヒントの重要な語に使われます | 166 |
| `FF336666` | 濃いティール | 13 |
| `FF66cc99` | 淡い緑 | 5 |
| `FFFF0000` | 赤 | 4 |

## サイズ {#size}

**サイズ**は、語句を大きくしたり小さくしたりします。数値ボックスで10～60のサイズを設定してから、**サイズ**を押します。標準のサイズは20です。

```game-text
<s=30>FOR SUPER EARTH!</s>
```

```game-text
Mission complete. <s=14>Mostly.</s>
```

> [!NOTE]
> ゲームのどの行もサイズを使っていませんが、チャットは使っています。字幕やメニューでサイズがどう見えるかはゲームが決めるため、MODを共有する前にゲーム内で確認してください。

## 強調 {#emphasis}

**強調**は、ヒントやブリーフィングが説明する用語のスタイルである`<i=1>`を書き込みます。プレビューでは斜体で表示されます。ゲーム内では強調のスタイルで表示されます。

```game-text
Welcome to the <i=1>Galactic Map</i>. Select <i=1>Missions</i> to play.
```

その他のスタイルはバーにありません。ゲームは、告知の見出しに`<i=3>`を、タイマーの数字の間に`<i=2>`を使っています。これらは手で入力してください。

```game-text
<i=3>STRATEGIC ADVISORY</i>
The Automaton <i=1>Jet Brigade</i> has been spotted.
```

## タイミング（字幕） {#timing-subtitles}

字幕は、`{start->end}`というタイミングマークで始まります。このマークは、その後ろの語句が表示される時間と消える時間を、セリフの開始からの秒数で設定します。長い字幕には、テキスト1つごとに複数のマークがあります。**タイミング**を押すと、カーソル位置に`{0.00->2.00}`が追加されるので、時間を入力してください。

```game-text
{0.00->1.85}Reinforcements inbound!
```

```game-text
{0.00->2.40}Stratagem coming in hot.
{2.40->4.10}Clear the landing zone!
```

セリフの新しい音声の長さが違う場合は、字幕の時間もそれに合わせて変更してください。ライブラリには、波形の上にセリフの長さが表示され、行の**字幕**のリンクで、ここに字幕が開きます。

## 改行 {#line-breaks}

**新しいテキスト**でEnterを押すと、新しい行が始まります。ゲームの長いテキスト（440行）では改行が使われています。一部の長い字幕も同様で、テキスト1つごとに1行になっています。

## ゲームが埋め込む部分 {#parts-the-game-fills-in}

ゲームは、行を表示するときに、一部を埋め込みます。これらの部分は変更せず、文言を書き換えるときは、語句と一緒に移動してください。

- **`#`の後ろにある大文字の語**（`#NAME`や`#COUNT`など）は、プレイヤー名や数字になります。プレビューでは、ボックスとして表示されます。
- **コードの代わりに名前が付いた色**（`<c=#PLAYER_COLOR>`など）は、プレイヤーの色のように、ゲームが選びます。プレビューでは、これらのタグで色が付く語句に下線が引かれます。

```game-text
<c=#PLAYER_COLOR>#NAME</c> DIED
```

```game-text
<c=#PLAYER_COLOR>#NAME</c> gave their life for <c=FFFFE900>Super Earth</c>
```

行がこれらの部分のどれかを失うと、エディターが警告します。
