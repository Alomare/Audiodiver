ライブラリとオーディオタブは同じレイアウトで、左にリスト、中央に開いている項目、右に詳細パネルがあります。サウンドトラックはレイアウトが異なります。詳しくは[サウンドトラック](wiki:soundtrack)を参照してください。**太字**の語は、[ゲーム音声の仕組み](wiki:game-audio)で説明しています。

## 左側のリスト {#the-list-on-the-left}

- **インデックス**は、音声を種類別に分類します。音楽、武器、敵などのカテゴリーの中に、*艦内にて*や*プライマリ武器*などのセクションがあります。各セクションには、開ける項目が並びます。項目は**曲**か**サウンドセット**のどちらかです。行の末尾の数字は、曲の長さ、またはセットに含まれるサウンドの数です。
- **すべてのアーカイブ**は、音声を含むすべての**アーカイブ**を表で表示します。列の見出しをクリックするとその列で並べ替え、もう一度クリックすると順序が逆になります。*インデックス*列のアイコンは、そのアーカイブを含むカテゴリーを示します。 すべてのアーカイブはインデックスより広い幅で始まり、それぞれドラッグした幅を保ちます。
- Helldivers 1 がインストールされていると、この2つの下にある **Helldivers 2** と **Helldivers 1** のタブでゲームを選べます。
- ライブラリでは、行末の「**+**」でプロジェクトに追加し、**✓**はプロジェクトにすでにあることを示します。カテゴリーとセクションの行にも**+**があり、その下に見えているものをすべて追加します。検索後は、この「**+**」で検索結果だけを追加します。
- オーディオタブのリストには、プロジェクトにあるものが表示されます。行、またはカテゴリーやセクションの行にある「**✕**」は、それをプロジェクトから削除し、プロジェクトでそこに加えた変更もすべて削除します。対象は、新しい音声（プロジェクト内の別の項目と共有しているスロットも含む）、追加したテイクとレイヤー、Make-Up Gain、音楽のキューポイントとサウンドトラックの設定です。新しい音声が消える場合は、先にAudiodiverが確認します。右クリックでも同じ操作ができ、{key:undo}で元に戻せます。
- 検索ボックスの隣にある{icon:collapse} **すべて折りたたむ**は、すべてのカテゴリーとセクションを折りたたみます。検索すると、一致したものが展開されます。

## 中央パネルの上部 {#the-top-of-the-middle-panel}

- **パスとタイトル**は、項目がインデックスのどこにあるか（*武器 ▸ プライマリ武器*、*ヘルダイバー ▸ ボイス*）と、その名前を示します。タイトル末尾の‹と›で、戻る・進むができます。
- **オリジナル**、**一部置き換え済み**、**置き換え済み**は、項目が現在何を再生するかを示します。オーディオタブにのみ表示されます。
- **アーカイブ …内**は、項目を含むアーカイブの名前と、それに続くゲームファイル内の**バンク**名を示します。アーカイブをクリックすると、すべてのアーカイブで開きます。

タイトルの下には、項目について補足する枠が並びます。横に並び、パネルが狭いと縦に積み重なります。

- {icon:transition} **この音楽と一緒に N 個のトランジションが再生されます**は、音楽にだけ表示されます。音楽に入る短いピースと、音楽から出る短いピースの数です。**表示**を押すと、それらと、それぞれが現在何を再生するかが一覧されます。
- {icon:order} **ゲームはこれらのスロットを別の順序で再生します**は、プレイリストがスロットを上から順に再生しない音楽に表示されます。**再生順**を押すと、[サウンドトラック](wiki:soundtrack)で開きます。
- {icon:link} **共有先**には、同じクリップの一部を再生している他のものが一覧されます。

ツールバー末尾の{icon:header}は、ヘッダーを隠したり、再び表示したりします。

## ツールバー {#the-toolbar}

{icon:through} **通し再生**は、曲全体をセグメントごとに、ゲームと同じ順序で再生します。灰色のボタンは**オリジナル**の音声を再生し、黄色のボタンは**置き換え済み**の音声を再生します。再生中は、現在位置がバーで表示されます。

ツールバーの先頭にあるチェックボックスで、すべてのスロットの選択と解除を切り替えます。ライブラリには、続いて**プロジェクトに追加**があります。オーディオタブには、次のツールがあります。

| ツール | 機能 |
|---|---|
| {icon:fill} **ファイルから一括割り当て** | ファイルをスロットに割り当てます。1スロットに1ファイルで、再生順とファイル名順に従います。 |
| {icon:fillpiece} **曲全体を一括割り当て** | すべてのパートのスロットに、パートごとに同じ方法で割り当てます。 |
| {icon:slice} **曲を切り分け** | 1曲を切り分けて、各スロットに1つずつ割り当てます。 |
| {icon:export} **エクスポート** | 項目、または選択したスロットを、WAV、FLAC、MP3、WEMのファイルとして保存します。隣の**エクスポートリスト**は、項目が入ると[エクスポートリスト](#the-export-list)を開きます。 |
| {icon:skip} **スキップ**、{icon:skipall} **すべてスキップ** | トランジションやスティンガーを短い無音に置き換えます。 |
| {icon:clear} **すべてクリア**、**このパートをクリア** | 表示中のすべてのスロット、またはパートのすべてのスロットから、新しい音声を削除します。 |

{icon:search} **スロットを検索**は、名前、ラベル、メモ、ファイル名、IDでリストを絞り込みます。サウンドセットでは、セリフの文言も検索できます。リストに一致するものがないときは、**その他の場所**に、一致する曲とサウンドセットが一覧されます。

検索の後ろにある{icon:id}は、バンク内のサウンドを[コンテナID](#container-ids)で一覧します。もう一度押すと、名前の表示に戻ります。

ツールバー末尾の{icon:header}と{icon:waves}は、ヘッダーと波形の表示・非表示を切り替えます。その後ろの「**?**」は、このセクションを開きます。波形ボタンは、スロットを1つ選択している間に使えます。

## パート {#parts}

ツールバーの下のタブで、開いている項目の**パート**を切り替えます。パートとは、曲のバイオームや強度、またはボイスの言語です。タブの数字は、長さまたはサウンドの数です。

トランジションとスティンガーには短いパートが多数あるため、各パートはスロットのリスト内の1行になります。この行はオリジナルを再生し、長さを表示し、無音のパートや他の音楽に属するパートに印を付けます。開いているパートのスロットは、その行のすぐ下に表示されます。別の行をクリックするとそのパートが開き、開いている行をクリックすると折りたたまれます。ツールバーの操作は、開いているパートに対して行われます。

## スロット {#the-slots}

各行は1つの**スロット**で、置き換え可能なゲーム内のクリップ1つに当たります。

- **音楽**では、**セグメント**が再生順に並びます。セグメントの最初の行にはセグメント名が表示され、その下の行は他の**レイヤー**です。
- **サウンド**は**グループ**で表示され、サウンドごとに1行があり、その下に**テイク**が折りたたまれています。行の▶は最初のテイクを再生します。行にファイルをドロップすると、テイクに順に割り当てられます。行を右クリックすると、すべてのテイクをまとめて割り当て、無音化、クリアできます。
- 行の左半分はオリジナルです。▶で再生でき、末尾に長さが表示されます。オーディオタブでは、右半分が置き換えです。▶で新しい音声を再生し、ファイル名をクリックすると別のファイルを選べ、✕で削除します。空のスロットには*音声をドロップ、またはファイルを選択*と表示されます。
- 行の先頭のチェックボックスは、Ctrl+クリックと同じように、スロットを選択に入れたり外したりします。チェックボックスをShift+クリックすると、範囲を選択できます。グループの行には、グループ内のすべてのテイク用のチェックボックスがあり、グループは折りたたまれたままです。ライブラリでは、**エクスポート**で選択したスロットだけを保存できます。オーディオタブでは、複数のスロットを選択すると、右パネルに**すべてに1つのファイルを選択**、**ファイルを選択**、**無音に置き換え**と、新しい音声を削除するボタンが表示されます。
- 行をダブルクリックすると再生します。それ以外の操作は、右クリックで行います。コピー、貼り付け、無音化、IDの操作もここにあります。
- エクスプローラーで音声ファイルをコピーし、スロットを選択して**Ctrl+V**を押してください。1つのファイルは、選択したすべてのスロットに入ります。複数のファイルはファイル名順に入り、スロットを1つだけ選択している場合は、そこから続けて割り当てられます。Ctrl+Vは、最後にコピーしたものを貼り付けます。エクスプローラーのファイルでも、Audiodiverでコピーしたスロットでも同じです。
- **Ctrl+C** は、ライブラリまたはオーディオタブで選択したスロットをコピーします。**Ctrl+V** はオーディオタブで選択したスロットに貼り付けるので、書き出しも読み込みも要りません。新しい音声があるスロットからは、その音声と設定がコピーされます。それ以外のスロットからはオリジナルがコピーされ、Helldivers 2 のクリップはそのまま入ります。

### 行のタグ {#tags-on-a-row}

| タグ | 意味 |
|---|---|
| {icon:link} **+3 キュー** / **+5 バンク** / **+8 件** | ゲームが同じクリップを、その数だけ他の場所でも再生しています。 |
| {icon:link} **他の 104 個のバンク**（グループの場合） | グループ内のすべてのサウンドが共有コピーです。すべての武器が持つ取り扱い音などが該当します。 |
| **ループ**、**×2** | セグメントは、ゲームが次に進むまで繰り返されるか、その回数だけ繰り返されます。 |
| *デザート*のような条件 | このスロットは**バリアント**で、条件を満たしたときだけ再生されます。 |
| **再生されない** | ゲームデータにこのクリップは記載されていますが、再生するものがありません。 |
| **変更禁止** | このクリップを置き換えると、音楽が途切れます。一括割り当てでは除外されます。 |
| **音声なし** | ゲームデータにこのクリップの名前はありますが、インストールされたゲームファイルには含まれていません。再生も置き換えもできません。 |
| **静かなドラム** | セグメントの別のレイヤーの下にある、ほとんど聞こえないドラムのレイヤーです。 |
| **まったく再生されない** | クリップはゲームファイルにありますが、ゲームがこれを再生することはありません。イルミネイトのVoidでの死亡時の音楽がその一例です。 |
| **このサウンドのみ** | 新しい音声はこのサウンドだけで再生されます。このクリップを再生する他のサウンドは、オリジナルのままです。[このサウンドのみ](wiki:adding-audio#only-this-sound)を参照してください。 |
| **他のサウンドで置き換え済み** | 別のサウンドが、**このサウンドのみ**を使って、このクリップの代わりに新しい音声を再生しています。このサウンドはオリジナルのままです。 |
| **−6 dB** | 新しい音声がないスロットで、オリジナルに設定したMake-Up Gainです。[スロットごとのMake-Up Gain](wiki:volume#make-up-gain-per-slot)を参照してください。 |
| 色付きのタグ | このスロットに関連するインデックスの項目です。タグをクリックすると開きます。 |

タグにポインターを合わせると、メモが表示されます。選択したクリップのメモは、詳細パネルにも表示されます。メモには、クリップが再生されるタイミングや、新しい音声の最小の長さなどの警告が書かれています。

### マーク {#marks}

| マーク | 意味 |
|---|---|
| ○ ◐ ● | オリジナル、一部置き換え済み、置き換え済み。 |
| ↝ | **トランジション**。2つの曲の間で再生されます。 |
| ✦ | **スティンガー**。音楽の上に重ねて再生されます。 |
| ×3 | 項目に**パート**が3つあります。 |
| **!** | オリジナルのトランジションが、新しい音楽の隣で再生されます。[ゲームが音楽を再生する仕組み](wiki:how-the-game-plays-music)を参照してください。 |

## スロットの下 {#under-the-slots}

選択したスロットの**波形**がここに表示されます。上がオリジナルで、オーディオタブでは下が置き換えです。時間とレベルの目盛りは共通で、**Entry**と**Exit**の位置が示されます。どちらも[Make-Up Gain](wiki:volume#make-up-gain-per-slot)を適用した状態で描画され、赤はフルスケールを超えた音声を示します。波形をクリックするとその位置から再生され、パネルの上端をドラッグするとサイズを変更できます。ツールバー末尾の{icon:waves}で非表示にできます。ライブラリでは、波形の上の行にスロットの説明が表示されます。ID（クリックでコピー）、長さ、スロットが再生されるタイミング、ゲームが他に再生する場所です。波形の周りの線は、クリップの[ボリュームカーブ](wiki:volume#volume-curves)です。

2つのスライダーで、両方の波形をズームします。右側の縦のスライダーは波形を高く表示して小さな音を見やすくし、波形の下の右側にあるスライダーは時間方向にズームして、EntryとExitを細かく配置できるようにします。波形上では、マウスホイールで時間方向にズームし、Ctrl+ホイールで波形を高くし、Shift+ホイールでスクロールします。時間方向にズームしているときは、波形の下の帯も一緒にスクロールします。2つのスライダーの間の隅にある{icon:reset}は、音声全体を元の倍率で表示し直します。スライダーを動かしている間は、つまみの上に0～100の数字が表示され、現在位置がわかります。別のスロットを選択しても、ズームは設定したままです。切り分けツールにも同じスライダーがあります。

## 詳細パネル {#the-details-panel}

オーディオタブでは、このパネルに選択したスロットの設定があります。スロットを置き換えているものが、ファイルか無音かが表示されます。ファイルには、エクスプローラーで表示するボタンがあり、無音には**元の長さを保つ**があります。その下には、**Make-Up Gain**（[詳しくはこちら](wiki:volume)）、**タイミングを新しい音声に合わせる**、**キューポイント**、**共有先**、メモがあります。新しい音声がないスロットには、**無音を使用**とオリジナルのMake-Up Gainがあります。音声の再生とファイルの選択は、スロットの行で行います。

複数のスロットを選択している場合、このパネルでは、そのすべてに対してMake-Up Gain、キューポイント、無音を設定します。**すべてに1つのファイルを選択**は、選択したすべてのスロットに1つのファイルを入れます。**ファイルを選択**は、リストの順とファイル名順で、各スロットにファイルを1つずつ入れます。

スロットを選択していないときは、パネルに、開いている項目のメモと、スロットのリストで使えるキーが表示されます。

ライブラリでは、選択したスロットの名前とID、スロットを選択していないときは開いている項目の名前とIDが、グローバルメモとともに表示されます。

## メモ {#notes}

スロットと、左側のリストの項目には、2種類のメモを付けられます。**プロジェクトメモ**はプロジェクトファイルに保存され、変更は元に戻せます。**グローバルメモ**は、このコンピューター上のメモファイルに保存され、すべてのプロジェクトとライブラリに表示されます。グローバルメモの変更は元に戻せません。ファイルの場所は、設定の[グローバルメモ](wiki:how-audiodiver-works#global-notes)に記載されています。ビルドにはメモは含まれません。

メモは詳細パネルの下部にあります。スロットを選択するとそのスロットのメモが、何も選択しないと項目のメモが表示されます。ライブラリに表示されるのは、グローバルメモだけです。**プロジェクトメモを追加**と**グローバルメモを追加**で、エディターが開きます。左側のリストの検索では、グローバルメモの文言も検索され、見つかった項目には{icon:note}が付きます。

メモはMarkdownで書きます。`#`は見出し、`-`は箇条書きの項目になり、`**bold**`と`*italic*`で語句を装飾し、`[text](https://…)`でリンクを作ります。入力ボックスの上のボタンは、選択した語句に同じ装飾を適用し、もう一度押すと装飾が外れます。入力中は、ボックス内で{key:undo}が使えます。ボックスの外をクリックするとメモが保存され、書式付きで表示されます。メモをクリックすると、再び編集できます。**プロジェクトメモを削除**と**グローバルメモを削除**でメモを削除します。文言が入っている場合は、先に確認が表示されます。

複数の場所で再生されるクリップには、種類ごとに1つのメモがあり、すべての場所に表示されます。ゲームのアップデートでクリップに新しいIDが付くと、メモは表示されなくなります。メモはファイルに残り、IDが元に戻ると再び表示されます。

## バー {#the-bars}

タブバーには主要なタブが並びます。最初にホームとツールがあります。その後ろの暗い色の帯には、開いているプロジェクト用のタブが、プロジェクトからテキストまで並び、プロジェクトタブにはプロジェクトのアイコンが表示されます。プロジェクトを開いている間は、帯の後ろにビルドがあり、末尾に{icon:updates}アップデート、Wiki、設定があります。バーはウィンドウの上端にあり、[設定 ▸ テーマ](app:settings/theme)の**タブバー**で別の辺に移せます。タブ名を表示にすると、上端や下端のバーではアイコンの横に名前が表示され、左端や右端のバーではタブにポインターを合わせたときに名前が表示されます。開いているタブは、そのページの色になり、帯の中では、開いているタブの縁がプライマリカラーになります。インデックスとすべてのアーカイブ、曲のパート、設定のセクションのように、ページ内のタブは、代わりに下線で示されます。ビルドの点は、プロジェクトの新しいビルドが必要なことを示し、アップデートの点は、Audiodiverの新しいバージョンがあることを示します。

下部のステータスバーには、元に戻す・やり直し、プロジェクトファイル、再生中の音声があります。再生中の音声をクリックすると、再生元に戻ります。ライブラリやオーディオタブではスロット、サウンドトラックでは曲とセグメントです。**音量**は、プレビューの音量を設定します。MODには影響しません。バージョン番号をクリックするとアップデートが開き、その隣の{icon:info}は[Audiodiverについて](app:about)を開きます。

### 履歴 {#history}

元に戻す・やり直しの隣の時計は**履歴**を開きます。プロジェクトを開いてから行った変更が、古い順に一覧され、それぞれの時刻が表示されます。プロジェクトが現在いる変更には印が付きます。前の変更をクリックすると、それ以降のすべての変更が一度に元に戻り、下にある灰色の変更をクリックすると、そこまでがやり直されます。**開いたときの状態**を押すと、すべて元に戻り、プロジェクトを開いた時刻が表示されます。元に戻す・やり直しは、リストが移動した位置から引き続き使えます。リストには、直近の200件の変更が保持されます。

### 通知 {#notifications}

*ロードアウト選択をマイMODに追加しました*や*マイMODを保存しました*のような短い確認は、ウィンドウの下部に短時間表示されます。読む必要がある通知や、元に戻す、フォルダーで表示などのボタンが付いた通知は、右下か、[設定 ▸ システム](app:settings/system)の**通知**で設定した隅に表示されます。

ステータスバー右端のベルには、これまでに表示された通知が新しい順に、それぞれの時刻とともに一覧されます。消えた通知を読み返せます。チュートリアルの案内や、**フォルダーで表示**の付いた通知のように、どこかへ案内した通知は、リストでクリックすると、再びそこへ案内します。リストには直近の100件が保持され、Audiodiverを再起動しても残ります。リストは通知を並べるだけで、自動的に何かを表示することはありません。

## ID {#ids}

どのスロットも、行末に**ストリームID**が表示されます。他の音声ツールがこの音声を一覧するときのIDです。バンク内にだけ音声が保存されているスロットには、代わりに**ソースID**が表示されます。IDをクリックするとコピーできます。行を右クリックすると、そのスロットのすべてのIDが表示されます。

- 音声を保持するファイルの64ビットの**ストリーム**ID
- クリップの**ソース**ID
- クリップを再生するバンク内の**サウンド**
- サウンドのテイクを保持する**コンテナ**
- クリップがレイヤーになっている音楽の**トラック**

どちらの検索ボックスでも、これらのどれでも入力して検索できます。

## コンテナID {#container-ids}

ツールバーの{icon:id}を押すと、バンク内のサウンドが、Wwiseのツールで一覧される形で表示されます。各サウンドは、テイクの真上にあるコンテナのIDで名前が付き、IDの前にコンテナの種類（Random、Sequence、Switch、Layer、Actor-Mixer）、後ろに通常の名前が付きます。上位のコンテナは別々の行に、階層が1つ深くなるごとに1段ずつ内側へずらして、バンクの順に表示されます。次の1つだけを保持するActor-Mixerは、1行にまとめられます。これらの行のIDをクリックするとコピーできます。スロット検索では、コンテナIDも検索できます。 コンテナの行、またはそのチェックボックスをクリックすると、その下のスロットがすべて選択されます。たとえばコンテナ全体の Make-Up Gain を設定するときに使えます。

## エクスポート {#exporting}

ツールバーの{icon:export} **エクスポート**は、エクスポートパネルを開きます。最初のタブは開いている項目を保存し、2番目のタブは[エクスポートリスト](#the-export-list)を保存します。右側には、エクスポートが書き込むフォルダーとファイルが、書き込まれる前に、実際の名前で一覧されます。

- **サウンド**または**スロット**：**選択中**（先にリストでスロットにチェックを付けます）、**置き換え済み**（オーディオタブ）、**すべて**。
- 音楽の**内容**：**スロットごと**、レイヤーをミックスした**セグメントごと**、通して再生した**曲全体**。サウンドトラックでは、**1回の戦闘**で、ゲームが再生するとおりに戦闘を保存します（[音楽のエクスポート](wiki:soundtrack#exporting)）。
- オーディオタブとサウンドトラックの**オーディオ**：**MODでの再生どおり**は、新しい音声があるスロットでは、設定したMake-Up Gainで新しい音声を、それ以外ではオリジナルを保存します。**両方**は、MODが変更する箇所すべてで、オリジナルの隣に置き換えたバージョンを追加し、ファイル名の末尾に「(original)」と「(replaced)」が付きます。ライブラリはオリジナルを保存します。
- **ファイル名**：**完全な名前**は項目の名前で始まり、**短い名前**はそれを省きます。**ソースID**は、他のMOD作成ツールがゲーム音声に名前を付けるのと同様に、ソースIDでスロットに名前を付けます。
- **形式**：WAV、FLAC、MP3、またはオリジナルのスロットではWEM。WEMはゲームにあるとおりのファイルで、再エンコードせずに、新しい音声として別のスロットに入れられます。

### 項目ごとにフォルダー {#a-folder-for-each-item}

**項目ごとにフォルダー**をオンにすると、各項目のファイルは、その項目の名前のフォルダーに入ります。オフのときは、すべてのファイルが保存先フォルダーに入ります。

### リードインとリングアウト {#lead-in-and-ring-out}

曲をセグメントごとにエクスポートすると、セグメントごとに1つのファイルが保存されます。**リードインとリングアウト**をオンにすると、各セグメントのEntryより前とExitより後の音声も含まれ、ゲームでのセグメントと同じように、ファイル同士が重なります。オフのときは、EntryからExitまでの音声だけが入り、ファイルは端と端でつながります。[タイミングとループ](wiki:timing-and-loops#entry-and-exit)を参照してください。

## エクスポートリスト {#the-export-list}

別々の場所からまとめて集めて、いっしょにエクスポートできます。スロット、テイクのグループ、インデックスの項目、カテゴリーやセクションの行、アーカイブを右クリックし、**エクスポートリストに追加**を選んでください。エクスポートパネルの**エクスポートリストに追加**は、パネルで選んだ設定のまま、開いている項目を追加します。ツールバーの**エクスポートリスト**で、リストが開きます。項目の名前を変更すると、保存先のフォルダー名が変わります。保存する内容と音声の種類を変更したり、項目を削除したりでき、すべてを1つの処理としてエクスポートできます。リストは、クリアするまで保持されます。

## 色 {#colours}

- **プライマリカラー**（スーパーアースイエロー）は、主要なボタンを塗り、置き換えた音声、編集、プロジェクトを示します。
- **セカンダリカラー**（青）は、リンク、開いているタブ、選択、フォーカスリングなど、ナビゲーションと情報に使われます。ライトテーマでは、本来プライマリカラーになる文字、線、薄い色にも使われます。
- 無彩色の灰色は、オリジナルを示します。

2つの色、テーマ、コントラスト、**ナイトモード**は、[設定 ▸ テーマ](app:settings/theme)で変更できます。
