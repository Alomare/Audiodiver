Helldivers 2は、多くのゲームで使われている音声エンジン**Wwise**で音声を再生します。Wwiseには、曲や名前の付いたファイルという考え方がありません。クリップをコンテナに格納し、すべてに番号を付け、次にどのクリップを再生するかを再生中に決めます。Audiodiverはこの構造を、プレイヤーにわかる形に戻して表示します。このページの用語は、画面に表示される用語です。

## 音声の保存場所 {#where-the-audio-is-stored}

大きいものから順に説明します。

1. **アーカイブ**は、ゲームの`data`フォルダー内のファイルの1つで、`2e24ba9dd702da24`のような16文字のコードが名前になっています。アーカイブには、たいてい武器、陣営の音楽、ある言語のボイスなど、1つの対象の音声が入っています。**すべてのアーカイブ**で一覧できます。
2. **バンク**は、アーカイブ内にあるWwiseのサウンドバンクです。クリップと、それを再生する**サウンド**が入っています。中央パネルの上部にある*アーカイブ …内*の行に、アーカイブとバンクの両方の名前が表示されます。
3. **サウンド**は、ゲームが起動できるもの1つで、*オートキャノンの発射音*や"Reloading!"がその例です。サウンドには**テイク**が1つ以上あり、再生のたびにそのうちの1つが再生されます。
4. **テイク**は、サウンドの録音1つです。ライフルの発射音にはテイクが複数あり、ゲームは同じ音が続かないように、ランダムに1つを選びます。置き換えで変更されるクリップが、テイクです。

音楽やセリフなどの長い音声は、**ストリーム**として扱われることが多くあります。これは、クリップがバンクの隣のアーカイブに保存されているという意味です。Audiodiverは、どちらの場合でもクリップを見つけます。

## 「シーケンス 3」や「テイク 2」と呼ばれるものが多い理由 {#why-many-things-are-called-sequence-3-or-take-2}

ゲームファイルには数字があるだけで、名前はありません。Audiodiverの名前は、コミュニティの資料（[Audiodiverについて ▸ クレジット](app:about)に一覧があります）と、Audiodiverが推定できる内容に基づいています。

- 名前のないシーケンスは、バンクの順に**シーケンス 1**、**シーケンス 2**のように呼ばれます。聴いて何なのかを確かめてください。シーケンスとは、再生のたびにゲームがその中から1つを選ぶテイクのグループです。
- 名前のないシーケンスのテイクは、**テイク 1**、**テイク 2**のように呼ばれます。セリフのように書き起こされたテイクは、話している内容が名前になります。
- 名前のないサウンドセットやアーカイブは、アーカイブのコードが名前になり、*名前はまだありません*と表示されます。

たとえば「シーケンス 4 › テイク 2」は、バンク内の4番目のシーケンスの2番目の録音です。シーケンスを置き換えるには、すべてのテイクに新しい音声を割り当ててください。そうしないと、ゲームがときどきオリジナルを選びます。

## その他の音声とゲームファイルに音声なし {#other-audio-and-no-audio-in-the-game-files}

サウンドセットの末尾に、名前や番号の付いたサウンドの後ろに、2つのグループが表示されることがあります。

- **その他の音声**は、バンクが保存または名前を記録しているものの、そのバンク内のどのサウンドも再生しないクリップです。通常は、別のバンクのサウンドがこれらを再生します。他のクリップと同じように再生や置き換えができますが、何に使われるのかという情報はありません。
- **ゲームファイルに音声なし**は、バンクのデータには名前があるものの、インストールされたゲームファイルには含まれていないクリップです。削除されたコンテンツか、インストールされていないゲームの一部です。▶ボタンは無効で、一括割り当てでは除外されます。

## 音楽の構成 {#how-music-is-put-together}

Helldivers 2の音楽は、アクションに合わせて変化するように作られています。Audiodiverでは、次の用語を使います。

- **キュー**は、セグメントのプレイリストで、ゲームデータが定義する1つの音楽です。スロットの「**+3 キュー**」というタグは、同じクリップが他の3つの曲でも再生されることを示します。
- **曲**は、インデックスに一覧されるもので、*ロードアウト選択*がその例です。1つのキュー、または関連する複数のキューで構成されます。
- **パート**は、曲の1つのキューで、タブとして表示されます（トランジションとスティンガーではリストの1行）。曲には、バイオーム、強度、ボイスの言語ごとにパートがある場合があります。各パートには、別々のスロットがあります。
- **セグメント**は、1つの単位として再生される音楽の区間で、**Entry**と**Exit**の位置があります。次のセグメントはExitで始まり、現在のセグメントの末尾は、その上に重なって鳴り続けます。
- **レイヤー**（ステム）は、セグメントが同時に再生する複数のクリップの1つです。各レイヤーは別々のスロットです。
- **スロット**は、クリップが再生される場所1つで、サウンドのテイクか、セグメントのレイヤーのどちらかです。音声はスロット単位で置き換え、1スロットに1ファイルを割り当てます。
- **バリアント**は、バイオームなどの条件を満たしたときだけ再生されるスロットです。行に条件が表示されます。
- **トランジション**（↝）は、2つの曲の間で再生される短いピースです。**スティンガー**（✦）は、音楽の上に重ねて再生される短いピースです。

詳しくは[ゲームが音楽を再生する仕組み](wiki:how-the-game-plays-music)を参照してください。

## ID {#ids}

すべてのクリップ、サウンド、バンク、キューには番号があり、ゲームファイルが使うのはこの番号だけです。メモや他のツールにあるIDを検索ボックスに貼り付けると、それがどこにあるかがわかります。詳細の上部には、スロットの**ストリームID**、または音声がバンク内にだけあるときは**ソースID**（クリップのID）が表示されます。ゲームのアップデートでIDが変わっても、プロジェクトは有効なままです。

## 用語集 {#glossary}

| 用語 | 意味 |
|---|---|
| アーカイブ | ゲームの`data`フォルダー内のファイル。バンクとストリームのクリップが入っています。 |
| 割り当て | スロットに設定したファイル、または無音。 |
| バンク | Wwiseのサウンドバンク。クリップと、それを再生するサウンドが入っています。 |
| カテゴリー、セクション | インデックスの分類で、武器 ▸ サポート武器のように表示されます。 |
| キュー | セグメントのプレイリスト。ゲームデータが定義する1つの音楽です。 |
| Entry、Exit | セグメントのキューポイント。Entryは開始とみなされる位置で、Exitは次のセグメントが始まる位置です。 |
| 一括割り当て | 複数のファイルを、再生順にスロットへ1回の操作で割り当てること。 |
| グループ | サウンドと、それが再生するテイクを1行にまとめて表示したもの。開閉できます。 |
| インデックス | 名前のあるすべてのものを分類した、ライブラリのリスト。 |
| レイヤー、ステム | セグメントが同時に再生するクリップ。 |
| 新しい音声 | スロットのオリジナルを置き換えるファイル。 |
| オリジナル | スロット内のゲーム本来の音声。 |
| パート | 曲の1つのキュー、またはボイスの1つの言語。タブとして表示されます。 |
| 曲 | プレイヤーが認識する音楽で、1つ以上のキューで構成されます。 |
| 通し再生 | 曲全体を、ゲームと同じセグメント間の受け渡しで再生すること。 |
| プロジェクト | `.audi`ファイル。MODで扱う内容と割り当てが記録されます。 |
| 置き換え済み | オリジナルの代わりに、新しい音声または無音を再生するスロット。 |
| セグメント | 1つの単位として再生される音楽の区間。 |
| 無音、スキップ | スロットを何もないものに置き換えること。スキップはトランジションをそうして、ゲームがすぐ次に進むようにします。 |
| スロット | ゲームのクリップが再生される場所1つ。 |
| サウンド | ゲームが起動するもの。再生のたびにテイクを1つ再生します。 |
| サウンドセット | 武器、敵、ボイスなど、1つの対象のサウンド。 |
| ソースID | ゲームファイル内のクリップの番号。 |
| スティンガー | 音楽の上に重ねて再生される短いフレーズ。 |
| ストリーム | バンクの外、その隣に保存されたクリップ。 |
| ストリームID | ストリームファイルの64ビットの番号。 |
| テイク | サウンドの録音1つ。ゲームがランダムに1つを選びます。 |
| トランジション | 2つの曲の間で再生される短いピース。 |
| バリアント | 条件を満たしたときだけ再生されるスロット。 |
| Wwise | ゲームが使っている音声エンジン。 |
