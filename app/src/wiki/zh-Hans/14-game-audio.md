Helldivers 2 使用 **Wwise** 播放音频，这是许多游戏都在用的音频引擎。Wwise 没有歌曲或具名文件的概念。它把片段存放在容器中，给所有东西编上数字，并在游戏过程中决定下一个播放哪个片段。Audiodiver 把这种结构还原成玩家能认出的东西，本页的术语就是界面上显示的术语。

## 音频存放在哪里 {#where-the-audio-is-stored}

从大到小：

1. **归档**是游戏 `data` 文件夹中的一个文件，以 16 个字符的代码命名，例如 `2e24ba9dd702da24`。一个归档通常包含一样东西的音频，例如一把武器、一个阵营的音乐，或某一语言的一套语音。**所有归档**列出了它们。
2. **音频库**是归档中的一个 Wwise 音频库。它包含片段以及播放这些片段的**声音**。中间面板顶部的 *位于归档……* 这一行同时指出归档和音频库。
3. **声音**是游戏可以触发的一样东西，例如*机炮射击*或 *"Reloading!"*。一个声音有一个或多个**变体**，每次播放其中一个。
4. **变体**是声音的一段录音。步枪射击有多个变体，游戏随机选取一个，让每次射击听起来都不一样。替换改掉的正是这个变体片段。

音乐和语音台词这类较长的音频通常是**流式存储**的，即片段存放在归档中音频库的旁边。无论哪种情况，Audiodiver 都能找到片段。

## 为什么许多东西叫“声音 3”或“变体 2” {#why-many-things-are-called-sound-3-or-take-2}

游戏文件中只有数字，没有名称。Audiodiver 中的名称来自社区文档（列在[关于 ▸ 致谢](app:about)中），以及 Audiodiver 能推断出的信息：

- 没有名称的声音按音频库中的顺序称为**声音 1**、**声音 2**，依此类推。试听一下就能知道它是什么。
- 未命名声音的变体称为**变体 1**、**变体 2**，依此类推。已转写的变体（例如语音台词）以其内容命名。
- 没有名称的声音集或归档以归档代码命名，并标有*尚未命名*。

例如，“声音 4 › 变体 2”是音频库中第四个声音的第二段录音。要替换一个声音，请为每个变体都提供新音频，否则游戏有时会选中原版。

## 其他音频和游戏文件中没有音频 {#other-audio-and-no-audio-in-the-game-files}

在声音集末尾、已命名和已编号的声音之后，可能出现两个组：

- **其他音频**收的是音频库存放或有名字、但库中没有任何声音播放的片段。通常由其他音频库中的声音播放它们。它们可以像任何片段一样播放和替换，但没有关于其用途的信息。
- **游戏文件中没有音频**包含音频库数据指名、但已安装的游戏文件中没有的片段。它们是被删减的内容，或游戏中未安装的部分。它们的 ▶ 按钮不可用，填充时会跳过它们。

## 音乐的构成 {#how-music-is-put-together}

Helldivers 2 的音乐随战况变化。Audiodiver 用以下术语描述它：

- **一段音乐**（cue）是由段落组成的播放列表，即游戏数据所定义的一首曲目。槽位上的 **+3 段音乐** 标签表示同一个片段还在另外三首曲目中播放。
- **曲目**是索引中列出的东西，例如*配装选择*。它是一段音乐，或几段互相关联的音乐。
- **部分**是曲目中的一段音乐，显示为一个选项卡（过渡段和插入乐段则显示为列表中的一行）。一首曲目可以为每个生物群系、每种强度或语音的每种语言各有一个部分。每个部分有一组独立的槽位。
- **段落**是作为一个单元播放的一段音乐，带有**入点**和**出点**。下一个段落从出点开始，当前段落的尾音会叠在其上渐渐消失。
- **层**（或称分轨）是段落同时播放的多个片段之一。每个层是一个独立的槽位。
- **槽位**是播放片段的一个位置，可以是声音的一个变体，也可以是段落的一个层。音频一次替换一个槽位，每个槽位一个文件。
- **版本**是只在某种条件下（例如某个生物群系）播放的槽位。该行会显示条件。
- **过渡段**（↝）是在两首曲目之间播放的短乐段。**插入乐段**（✦）是叠加在音乐之上播放的短乐段。

[游戏如何播放音乐](wiki:how-the-game-plays-music)有更多细节。

## ID {#ids}

每个片段、声音、音频库和每段音乐都有一个编号，游戏文件只使用这些编号。将笔记或其他工具中的 ID 粘贴到搜索框中，即可找到它的位置。详情顶部显示槽位的**流 ID**；如果音频只在音频库中，则显示**源 ID**（片段 ID）。游戏更新更改 ID 后，项目仍然有效。

## 术语表 {#glossary}

| 词语 | 含义 |
|---|---|
| 归档 | 游戏 `data` 文件夹中的文件。包含音频库和流式存储的片段。 |
| 分配 | 分配给槽位的文件或静音。 |
| 音频库 | Wwise 音频库，包含片段以及播放这些片段的声音。 |
| 类别、分区 | 索引对内容的分类方式，例如“武器 ▸ 支援武器”。 |
| 一段音乐（cue） | 由段落组成的播放列表，即游戏数据所定义的一首曲目。 |
| 入点、出点 | 段落的提示点。入点是段落算作开始的位置，出点是下一个段落开始的位置。 |
| 填充 | 一次操作中按播放顺序将多个文件分配给槽位。 |
| 组 | 一个声音及其可选用的变体，显示为可展开的一行。 |
| 索引 | 资源库中所有有名称的内容的分类列表。 |
| 层、分轨 | 段落同时播放的片段。 |
| 新音频 | 替换槽位原版的文件。 |
| 原版 | 槽位中的游戏音频。 |
| 部分 | 曲目中的一段音乐，或语音的一种语言，显示为选项卡。 |
| 曲目 | 玩家能认出的音乐，由一段或多段音乐组成。 |
| 连续播放 | 以游戏所用的段落交接方式播放整首曲目。 |
| 项目 | `.audi` 文件，记录模组处理的内容和各项分配。 |
| 已替换 | 播放新音频或静音、而不播放原版的槽位。 |
| 段落 | 作为一个单元播放的一段音乐。 |
| 静音、跳过 | 用空内容替换槽位。“跳过”对过渡段这样做，让游戏直接继续。 |
| 槽位 | 播放游戏片段的一个位置。 |
| 声音 | 游戏触发的东西。每次播放一个变体。 |
| 声音集 | 一样东西的所有声音，例如一把武器、一种敌人或一套语音。 |
| 源 ID | 片段在游戏文件中的编号。 |
| 插入乐段 | 叠加在音乐之上播放的短乐段。 |
| 流 | 存放在音频库旁边（而非其中）的片段。 |
| 流 ID | 流文件的 64 位编号。 |
| 变体 | 声音的一段录音。游戏随机选取一个。 |
| 过渡段 | 在两首曲目之间播放的短乐段。 |
| 版本 | 只在某种条件下播放的槽位。 |
| Wwise | 游戏使用的音频引擎。 |
