资源库和音频选项卡使用同一种布局：左侧是列表，中间是打开的条目，右侧是详情面板。配乐的布局不同，参见[配乐](wiki:soundtrack)。**粗体**的词语在[游戏音频详解](wiki:game-audio)中有解释。

## 左侧的列表 {#the-list-on-the-left}

- **索引**按内容对音频分类。音乐、武器、敌人等类别下有*舰船上*、*主武器*等分区。每个分区列出可以打开的内容，可以是一首**曲目**，也可以是一个**声音集**。行末的数字是曲目的时长，或声音集中声音的数量。
- **所有归档**以表格显示每个包含音频的**归档**。点击列标题可按该列排序，再次点击可反转顺序。*索引*列中的图标表示哪些类别包含该归档。 所有归档的初始宽度大于索引，两者各自保留你拖动后的宽度。
- 安装了 Helldivers 1 后，这两项下方的 **Helldivers 2** 和 **Helldivers 1** 选项卡用于选择游戏。
- 在资源库中，行末的 **+** 会将该行添加到项目，**✓** 表示项目中已有它。类别行和分区行也有 **+**，会添加其下所有可见的内容。搜索后，这个 **+** 只添加搜索结果。
- 在音频选项卡中，列表显示项目中已有的内容。行上（或类别行、分区行上）的 **✕** 会将其从项目中移除，同时移除项目在其中做的全部更改：新音频（包括项目中另一个条目共用的槽位中的新音频）、添加的变体和层、Make-Up Gain，以及音乐的提示点和配乐设置。如果这样会移除新音频，Audiodiver 会先询问。右键点击也能做到同样的事，{key:undo} 可以恢复。
- 搜索框旁的 {icon:collapse} **全部折叠**会折叠所有类别和分区。搜索会展开所有匹配的内容。

## 中间面板的顶部 {#the-top-of-the-middle-panel}

- **路径和标题**显示条目在索引中的位置（*武器 ▸ 主武器*、*绝地潜兵 ▸ 语音*）以及它的名称。标题末尾的 ‹ 和 › 用于后退和前进。
- **原版**、**部分替换**或**已替换**显示条目当前播放的内容，这一项只在音频选项卡中出现。
- **位于归档……** 指出包含该条目的归档，后面是游戏文件中的**音频库**名称。点击归档可在“所有归档”中打开它。

标题下方有一排方框，进一步说明该条目。它们并排放置，面板较窄时会上下堆叠：

- {icon:transition} **有 N 个过渡段在这段音乐旁播放**只在音乐中出现。它统计进入和离开这段音乐的短乐段。**显示**会列出它们以及每个当前播放的内容。
- {icon:order} **游戏会以另一种顺序播放这些槽位**出现在播放列表不按从上到下播放槽位的音乐中。**播放顺序**会在[配乐](wiki:soundtrack)中打开它。
- {icon:link} **与……共用音频**列出播放部分相同片段的其他内容。

工具栏末尾的 {icon:header} 可隐藏标题区，再按一次则重新显示。

## 工具栏 {#the-toolbar}

{icon:through} **连续播放**按游戏使用的顺序，逐段播放整首曲目。灰色按钮播放**原版**音频，黄色按钮播放**已替换**音频；播放时，进度条会显示播放位置。

工具栏开头是一个复选框，用于选中所有槽位或清除选择。在资源库中，其后是**添加到项目**；在音频选项卡中，其后是以下工具：

| 工具 | 作用 |
|---|---|
| {icon:fill} **从文件填充** | 用文件填充槽位，每个槽位一个文件，按播放顺序和文件名顺序。 |
| {icon:fillpiece} **填充整首曲目** | 以同样的方式逐个部分填充每个部分的槽位。 |
| {icon:slice} **切分歌曲** | 将一首歌曲切成若干段，每个槽位一段。 |
| {icon:export} **导出** | 将条目或所选槽位保存为 WAV、FLAC、MP3 或 WEM 文件。列表中有内容后，旁边的**导出列表**会打开[导出列表](#the-export-list)。 |
| {icon:skip} **跳过**、{icon:skipall} **跳过全部** | 将过渡段或插入乐段替换为短暂的静音。 |
| {icon:clear} **全部清除**、**清除此部分** | 移除所显示的每个槽位的新音频，或该部分每个槽位的新音频。 |

{icon:search} **搜索槽位**按名称、标签、备注、文件名或 ID 筛选列表。在声音集中，它还能查找语音台词的文字。如果列表中没有匹配项，**其他位置**会列出有匹配项的曲目和声音集。

搜索框后的 {icon:id} 按[容器 ID](#container-ids) 列出音频库中的声音。再按一次可恢复按名称显示。

工具栏末尾的 {icon:header} 和 {icon:waves} 可隐藏或显示标题区和波形，其后的 **?** 会打开本节。波形按钮在选中一个槽位时可用。

## 部分 {#parts}

工具栏下方的选项卡用于在打开条目的各个**部分**之间切换。部分是曲目的不同生物群系或强度，或者语音的不同语言。选项卡上的数字是时长或声音数量。

过渡段和插入乐段有许多短小的部分，因此每个部分改为槽位列表中的一行。这一行可以播放原版、显示时长，并标出静音或属于其他音乐的部分。打开部分的槽位就列在这一行正下方。点击另一行可打开该部分，点击已打开的行可将其折叠。工具栏作用于打开的部分。

## 槽位 {#the-slots}

每一行是一个**槽位**，即一个可以替换的游戏片段。

- **音乐**按播放顺序列出**段落**。段落的第一行显示段落名称，其下各行是其他**层**。
- **声音**以**组**显示，每个声音一行，其**变体**折叠在下面。这一行上的 ▶ 播放第一个变体。拖放到这一行上的文件会按顺序填充各个变体。右键点击这一行可一次填充、静音或清除所有变体。
- 行的左半部分是原版。▶ 播放它，时长显示在末尾。在音频选项卡中，右半部分是替换音频。▶ 播放新音频，点击文件名可选择其他文件，✕ 可将其移除。空槽位显示*拖入音频或选择文件*。
- 行首的复选框可将槽位加入或移出选择，与 Ctrl+点击相同。在复选框上按住 Shift 可选择一个范围。组的那一行有一个复选框，对应组中所有变体，且组保持折叠。在资源库中，**导出**可以只保存所选的槽位。在音频选项卡中，选中多个槽位后，右侧面板会有**为全部选择同一个文件**、**选择多个文件**、**替换为静音**以及移除新音频的按钮。
- 双击行可播放它。右键点击可进行其他所有操作，包括复制、粘贴、静音和查看 ID。
- 在资源管理器中复制音频文件，选中槽位后按 **Ctrl+V**。一个文件会放入每个选中的槽位。多个文件会按文件名顺序放入；如果只选中一个槽位，则从该槽位开始依次填充。Ctrl+V 粘贴最后复制的内容：资源管理器中的文件，或在 Audiodiver 中复制的槽位。
- **Ctrl+C** 复制在资源库或音频选项卡中选中的槽位。**Ctrl+V** 将其粘贴到音频选项卡中选中的槽位，无需导出和导入。有新音频的槽位提供该音频及其设置。其他槽位提供原版音频，Helldivers 2 的片段会原样放入。

### 行上的标签 {#tags-on-a-row}

| 标签 | 含义 |
|---|---|
| {icon:link} **+3 段音乐** / **+5 个音频库** / **+8 处** | 游戏在另外这么多处播放同一个片段。 |
| {icon:link} **在其他 104 个音频库中**（在组上） | 组中的每个声音都是共用的副本，例如每把武器都带有的操作声音。 |
| **循环**、**×2** | 该段落会一直重复，直到游戏进入下一段，或重复相应的次数。 |
| 条件，例如*沙漠* | 此槽位是一个**版本**，只在满足条件时播放。 |
| **从未听到** | 游戏数据列出了这个片段，但没有哪一处会播放它。 |
| **请勿改动** | 替换此片段会让音乐卡顿。填充时会跳过它。 |
| **无音频** | 游戏数据中有这个片段的名称，但已安装的游戏文件中没有它。没有可播放或替换的内容。 |
| **轻柔鼓声** | 段落中另一层下几乎听不见的鼓声层。 |
| **从不播放** | 片段在游戏文件中，但游戏从不播放它。光能者虚空的死亡音乐就是一个例子。 |
| **仅此声音** | 新音频只在此声音中播放。播放该片段的其他声音保留原版。参见[仅此声音](wiki:adding-audio#only-this-sound)。 |
| **已在其他 1 个声音中替换** | 另一个声音通过**仅此声音**，在此片段的位置播放新音频。此声音保留原版。 |
| **−6 dB** | 没有新音频的槽位中，原版上的 Make-Up Gain。参见[每个槽位的 Make-Up Gain](wiki:volume#make-up-gain-per-slot)。 |
| 彩色标签 | 与此槽位相关的索引条目。点击标签可打开它。 |

将鼠标悬停在标签上可阅读说明。所选片段的说明显示在详情面板中。说明描述片段何时播放，或给出警告，例如新音频的最短时长。

### 标记 {#marks}

| 标记 | 含义 |
|---|---|
| ○ ◐ ● | 原版、部分替换、已替换。 |
| ↝ | **过渡段**，在两首曲目之间播放。 |
| ✦ | **插入乐段**，在音乐之上播放。 |
| ×3 | 该条目有三个**部分**。 |
| **!** | 原版过渡段在新音乐旁播放。参见[游戏如何播放音乐](wiki:how-the-game-plays-music)。 |

## 槽位下方 {#under-the-slots}

这里显示所选槽位的**波形**。原版在上方；在音频选项卡中，替换音频在下方，两者使用相同的时间和电平刻度，并标出**入点**和**出点**。两者都按各自的 [Make-Up Gain](wiki:volume#make-up-gain-per-slot) 绘制，红色表示超出满刻度的音频。点击波形可从该位置开始播放，拖动面板的上边缘可调整其大小。工具栏末尾的 {icon:waves} 可隐藏波形。在资源库中，波形上方的一行描述该槽位：显示 ID（点击可复制）、时长、槽位何时播放，以及游戏还在哪些地方播放它。 波形周围的线是片段的[音量曲线](wiki:volume#volume-curves)。

两个滑块用于缩放两个波形。右侧竖直的滑块可将波形拉高，以显示较轻的音频；波形下方右侧的滑块可放大时间轴，以便精确放置入点和出点。在波形上，鼠标滚轮放大时间轴，Ctrl+滚轮拉高波形，Shift+滚轮滚动。放大时间轴后，波形下方的长条也会滚动。滑块之间角落里的 {icon:reset} 可重新以满刻度显示整段音频。移动滑块时，滑块上方会显示 0 到 100 的数字，表示滑块的位置。选择其他槽位时缩放保持不变，切分工具也有相同的滑块。

## 详情面板 {#the-details-panel}

在音频选项卡中，此面板包含所选槽位的设置。它显示替换该槽位的内容：文件或静音。文件旁有按钮，可在资源管理器中显示该文件；静音则有**保持原始时长**。下方是 **Make-Up Gain**（[详见此处](wiki:volume)）、**让时序适配新音频**、**提示点**、**与……共用**以及备注。没有新音频的槽位有**使用静音**和原版的 Make-Up Gain。播放音频、选择文件都在槽位行上操作。

选中多个槽位时，面板会为所有选中的槽位设置 Make-Up Gain、提示点或静音。**为全部选择同一个文件**会在每个选中的槽位中放入同一个文件，**选择多个文件**则按列表顺序和文件名顺序为每个槽位各放入一个文件。

未选中槽位时，面板显示打开条目的备注以及槽位列表的按键。

在资源库中，面板显示所选槽位的名称和 ID；未选中槽位时显示打开的条目，并附上对应的全局备注。

## 备注 {#notes}

槽位以及左侧列表中的条目可以有两种备注。**项目备注**保存在项目文件中，撤销可还原对它的更改。**全局备注**保存在本机的备注文件中，在每个项目和资源库中都会显示。撤销不会还原全局备注，备注文件的位置见设置中的[全局备注](wiki:how-audiodiver-works#global-notes)。构建不包含备注。

备注位于详情面板底部。选中槽位可查看该槽位的备注，不选任何内容则查看条目的备注。资源库只显示全局备注。**添加项目备注**和**添加全局备注**会打开编辑器。在左侧列表中搜索时也会查找全局备注中的文字，以这种方式找到的结果标有 {icon:note}。

备注使用 Markdown 编写。`#` 开始一个标题，`-` 开始一个列表项，`**bold**` 和 `*italic*` 标记文字，`[text](https://…)` 创建链接。框上方的按钮对所选文字执行相同的操作，再按一次则取消标记。输入时，{key:undo} 在框中可用。点击其他位置可保存备注并显示格式化后的效果。点击备注可再次编辑。**删除项目备注**和**删除全局备注**会删除备注；如果备注中有文字，会先询问。

在多处播放的片段每种备注只有一条，在每一处都会显示。游戏更新为片段分配新 ID 后，备注就不再显示。它仍保留在文件中，如果该 ID 恢复，备注会重新显示。

## 各个栏 {#the-bars}

选项卡栏放着主要的选项卡。最前面是主页和工具。之后颜色较深的一栏放着当前项目的选项卡，从项目到文本，项目选项卡显示项目图标。打开项目时，构建位于这一栏之后，{icon:updates} 更新、Wiki 和设置位于末尾。选项卡栏沿窗口顶部排列，[设置 ▸ 主题](app:settings/theme)中的**选项卡栏**可将它放到另一侧。开启选项卡名称时，位于顶部或底部的栏会在图标旁显示名称，位于左侧或右侧的栏会在指针移到选项卡上时显示名称。打开的选项卡使用其页面的颜色，在深色栏中，打开的选项卡带有主色边缘。页面内的选项卡，例如索引和所有归档、曲目的各个部分或设置的各个分区，则改为加下划线。构建上的圆点表示项目需要重新构建，更新上的圆点表示有新版本的 Audiodiver 可用。

底部的状态栏有撤销和重做、项目文件以及正在播放的音频。点击正在播放的音频可回到播放它的位置：资源库或音频选项卡中的槽位，或配乐中的曲目和段落。**音量**设置预览音量，不影响模组。版本号可打开“更新”，旁边的 {icon:info} 可打开[关于](app:about)。

### 历史记录 {#history}

撤销和重做旁边的时钟可打开**历史记录**，也就是项目打开以来所有更改的清单，最早的在前，每项都标明更改时间。项目当前停在哪项更改，那一项会有标记。点击较早的一项可一次撤销其后的所有更改，点击更下方的灰色项可重做到该项。**打开时的状态**会撤销全部更改，并显示项目打开的时间。无论列表跳到哪里，撤销和重做都能继续使用，列表保留最近 200 项更改。

### 通知 {#notifications}

简短的确认消息，例如*已将配装选择添加到我的模组*或*已保存我的模组*，会在窗口底部短暂显示。需要阅读的通知，或带有“撤销”“在文件夹中显示”等按钮的通知，显示在右下角，或显示在[设置 ▸ 系统](app:settings/system)中**通知**所设的角落。

状态栏右端的铃铛按从新到旧列出已显示过的通知及其时间，以便在通知消失后再次阅读。能跳转的通知（例如教程入口，或带**在文件夹中显示**的通知），在列表里点一下会再次跳到同一位置。列表保留最近 100 条，Audiodiver 重启后也会保留。它只列出通知，从不自行弹出任何内容。

## ID {#ids}

每个槽位在行末显示一个**流 ID**，其他音频工具也用这个 ID 列出它。音频只存放在音频库中的槽位则显示**源 ID**。点击 ID 可复制。右键点击行可查看该槽位的所有 ID：

- 音频所在文件的 64 位**流** ID
- 片段的**源** ID
- 音频库中播放该片段的**声音**
- 存放该声音各变体的**容器**
- 以该片段为层的音乐**音轨**

两个搜索框都接受其中任何一种 ID。

## 容器 ID {#container-ids}

按工具栏上的 {icon:id}，可以像 Wwise 工具那样列出音频库中的声音。这时，每个声音以变体正上方那个容器的 ID 命名，ID 前面是容器类型（Random、Sequence、Switch、Layer 或 Actor-Mixer），后面是平常的名称。更上层的容器各占一行，每深一级就多缩进一级，按音频库中的顺序排列。只包含下一个容器的 Actor-Mixer 共用一行。点击这些行上的 ID 可复制。槽位搜索也能查找容器 ID。 点击容器所在行或其勾选框，可选中其下的所有槽位，例如用来设置整个容器的 Make-Up Gain。

## 导出 {#exporting}

工具栏上的 {icon:export} **导出**会打开导出面板。第一个选项卡保存打开的条目，第二个保存[导出列表](#the-export-list)。在写入任何内容之前，面板右侧会列出导出将写入的文件夹和文件，以及它们的名称。

- **声音**或**槽位**：**所选**（先在列表中勾选槽位）、**已替换**（在音频选项卡中）或**全部**。
- **内容**（音乐）：**每个槽位**、混合各层的**每个段落**，或连续播放的**整首曲目**。在配乐中，**一场战斗**会按游戏里的播放方式保存整场战斗（[导出音乐](wiki:soundtrack#exporting)）。
- **音频**（音频选项卡和配乐）：**按模组的播放效果**会在有新音频的槽位中保存新音频（应用已设置的 Make-Up Gain），其他地方保存原版。**两者**会在模组有更改的每一处，在原版旁边加上替换后的版本，这些文件名以 *（原版）* 和 *（已替换）* 结尾。资源库保存原版。
- **文件名**：**完整名称**以条目名称开头，**简短名称**省略条目名称，**源 ID** 按源 ID 为每个槽位命名，与其他模组工具为游戏音频命名的方式相同。
- **格式**：WAV、FLAC、MP3，原版槽位还可选 WEM。WEM 是与游戏中完全相同的文件，作为新音频放入其他槽位时无需重新编码。

### 每个条目一个文件夹 {#a-folder-for-each-item}

开启**每个条目一个文件夹**后，每个条目的文件会放入以其命名的文件夹。关闭时，所有文件都放入目标文件夹。

### 前导和余音 {#lead-in-and-ring-out}

按段落导出曲目时，每个段落保存为一个文件。**前导和余音**会包含每个段落入点之前和出点之后的音频，使这些文件像游戏中的段落一样相互重叠。关闭时，文件只包含从入点到出点的音频，可以首尾相接。参见[时序和循环](wiki:timing-and-loops#entry-and-exit)。

## 导出列表 {#the-export-list}

把来自不同位置的内容收集起来一起导出。右键点击槽位、变体组、索引条目、类别行或分区行，或者归档，然后选择**添加到导出列表**。导出面板中的**添加到导出列表**会按其中所做的选择添加打开的条目。工具栏上的**导出列表**可打开该列表。可以重命名条目，用它给放入的文件夹起名；可以更改条目保存的内容和音频、移除条目，并把所有内容作为一项任务导出。列表会一直保留，直到将其清除。

## 颜色 {#colours}

- **主色**（超级地球黄）用于填充主要按钮，并标记已替换的音频、编辑和项目。
- **辅助色**（蓝色）用于导航和信息，例如链接、打开的选项卡、选择和焦点框。在浅色主题中，它还用于本应使用主色的文字、线条和色调。
- 中性灰色标记原版。

可在[设置 ▸ 主题](app:settings/theme)中更改这两种颜色、主题、对比度和**夜间模式**。
