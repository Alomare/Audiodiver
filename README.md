# Audiodiver

A desktop editor for Helldivers 2 audio mods: find the game's music, sounds and voices, replace them with new audio,
and build a mod for [HD2 Arsenal](https://github.com/Orbit-Studios/hd2arsenal-release/releases).

> [!WARNING]
> This software was developed entirely by Claude Opus 5.5. While I understand the concerns this may raise, I highly
> value quality, compatibility and performance, and would not put out anything without proper care and quality
> assurance. This was made for myself and for everyone else in the modding community. Thank you!

## Status

There are no releases yet. To build it from source, see [CONTRIBUTING.md](CONTRIBUTING.md).

## Questions and feedback

Ask on the [Helldivers 2 Modding Discord](https://discord.gg/helldiversmodding). Bugs go to
[Issues](https://github.com/Alomare/Audiodiver/issues).
