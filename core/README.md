# audiodiver (core)

A headless library and command-line tool that builds Helldivers 2 audio replacement mods from a `.audi` project into a verified HD2 Arsenal ZIP. The editor (`../app`) runs it as a local API server.

```
pip install -e "core[loudness,test]"     # loudness = optional Wwise analysis
python -m audiodiver new my.audi --name "My Mod" --from-folder replacers
python -m audiodiver build my.audi       # -> build/<name>-<version>.zip (or the project's build_folder, or --out DIR)
python -m audiodiver inspect some.patch_0   # what a patch changes against the current game
python -m audiodiver index --rebuild
python -m audiodiver serve --port 8765 --token dev   # the editor's API (the desktop app starts this itself)
python -m pytest core                    # unit tests + golden builds of the three mods (needs the game)
python core/tools/import_sounds.py       # dev: the Index's sound data, from the community's workbook (see the file)
python core/tools/import_subtitles.py    # dev: each voice line's subtitle and the names of clips without words (S7)
python core/tools/import_logo.py         # dev: the default mod icon and the app icon's source, from assets/logo
python core/tools/import_bank_history.py OLD_INDEX BUILD   # dev, after a game update: what the banks lost and gained
```

The build needs ffmpeg, wav2wem and vgmstream-cli (see `audiodiver/wem.py`). The core finds the game folder through Steam, using the registry to locate Steam. The editor's Settings ▸ System can choose another folder, and the core stores that choice in `%LOCALAPPDATA%\Audiodiver\settings.json` (`game_data`). If no folder is chosen, the `HD2_DATA` environment variable takes priority over Steam. The caches (the audio index, encoded WEMs and the Wwise scratch project), the log and the global notes (`notes.json`) are also in `%LOCALAPPDATA%\Audiodiver`, or wherever `AUDIODIVER_CACHE` names (a portable copy of the app sets it to its `data` folder). A release carries the core in an embeddable Python with the tools beside it (`app/scripts/release.py`). The core rebuilds the index when the game's files change.

| Module | Role |
|---|---|
| `game.py` | finds the game, reads packages from the slim bundles (vendored `_vendor/slim.py`, MIT) and the voice packs next to them (DSAR files, one set per installed language), murmur64; the game's version (Steam's build id), which a build notes in its project |
| `index.py` | which banks hold or play each sound, which archives hold each bank or stream, which language a voice bank is in, and the ids of every bank's objects (an object is often copied into many banks); cached per game version |
| `bank.py`, `music.py` | Wwise v154 bank chunks, a node's settings (its prop bundle) and music objects (round-trip byte-identical) |
| `patch.py` | the surgical patch writer: copies vanilla banks and changes only the replaced audio, its sizes, its timing and its gain, plus exactly what a project adds and an imported mod's settings; `verify` enforces that. A segment takes the project's cue points only where one of its tracks plays new audio, and an Entry at or after the Exit stops the build (`CueError`) |
| `biome.py`, `_vendor/ssr/` | the fix for the music that stays silent on seven planet biomes, from Sound Systems Rebalanced (0BSD), a project setting (`biome_fix`, off by default): a build's `music_init` starts from the fixed bank, so the fix stays whichever music_init loads; `patch.diff` compares a music_init that carries it with the fixed one |
| `addition.py` | audio added to the game's: a new take in a random container, a layer that plays with a container (through its switch or layer parent, or a twin of each play action), a clip of its own for one Sound. Every copy of what it changes gets the same change, under new 30-bit ids the game doesn't use; `check` verifies a patched bank against the plan. Reading a mod's patch (`from_patch`), the game's objects of an older version that the mod's bank copies still have aren't taken for the mod's: `data/bank_history.json` (`tools/import_bank_history.py`) lists what each bank lost and gained since earlier builds, and the fingerprints of objects the game changed since (`bank.fingerprint`, kept in the index). A copy that is another bank's (a tool that merges an object's copies across banks) isn't the mod's either (`merged`) |
| `wem.py`, `akd.py` | WAV→WEM encoding; optional Wwise loudness/HDR analysis chunk |
| `project.py`, `build.py`, `cli.py` | the `.audi` format, the build pipeline (an imported mod's audio keeps its own encoding: `keep_encoding`; a sound goes into the project's banks, an imported mod's or the list's, unless `every_bank`: `reach`; music keeps every bank), the CLI |
| `projectfiles.py` | a project's folder: which files it uses, whether its folder is its own (`own_folder`), moving it into one, collecting files from outside into `audio/added`, the files nothing uses (to the Recycle Bin), and packs: a ZIP of the project and its files (`.audipack`), without builds |
| `installed.py` | the installed mods (HD2 Arsenal's library and the game's `data/*.patch_N`) checked for sound banks of an older game version: older copies of actor-mixers other banks share (they can mute sounds far beyond the mod, like all gunfire), or banks an older version had |
| `repatch.py` | finding a mod's patches in a `.patch_N`, a folder or a ZIP, with what a mod manager's manifest says (name, icon, id, options; without one, the file's name less what a download added), a folder's patches as one part in load order, and packing the mod again as it was with new patches; `Session.repatch` rebuilds them on the current game |
| `arsenal.py` | the Arsenal ZIP/manifest packager, and the icon: an image, or the default one (Audiodiver's logo, `data/icon.png`), with a border and rounded corners |
| `cuemap.py` | every piece of music the game can play, walked from the music root switches and events; cached per game version |
| `catalog.py`, `data/` | names for people: every music cue in the game's own structure, cue and slot names, locks. `data/catalog.json` is hand-curated; `names.json` (cracked Wwise names) and `labels.json` come from dictionary attacks on the Wwise names and the music workbook (`tools/import_knowledge.py`); `notes.json` (hand-kept) names and explains single clips, with warnings and minimum lengths. Shown texts follow the app's writing rules in `app/README.md`. They name no people or sources (those are in the app's Credits) and give no testing status |
| `musiclist.py`, `data/music.json` | the music as the Index lists it: sections in mission order, items a player would recognise (one per faction role for combat: arrival, exploring, battle...), transitions named by what they connect, and which transitions or stingers sit next to which music |
| `library.py`, `data/sounds.json`, `banks.json`, `voices.json`, `subtitles.json` | the Library: the Index (the music, then the sound sets the community has named, by category; Weapons by loadout slot, from `WEAPONS` in `tools/import_sounds.py`, and an id a set had before a rename or a move still finds it) and All Archives (every archive with audio in it). A bank opens as its sounds, grouped by take and labelled with what a voice line says: its subtitle (`subtitles.json`: which one, and whether the id is certain or one of several with the same words), else the community's transcript, else the call another voice built the same way makes in its place. Clips without words are named by what they are ("Grunt 3", per bank) and a voice bank lists the ones it holds for other banks by kind. `subtitle_lines` goes back from subtitles to the voice lines that say them, in one language's voices. `sounds.json`, `banks.json` and `voices.json` are written by `tools/import_sounds.py`, `subtitles.json` by `tools/import_subtitles.py` from the S7 spike's matches |
| `titles.py` | title case for every name the Library shows |
| `strings.py` | the game's text: string tables (one per table and language, in archive 9ba626afa44a3aa3), read, searched and written back whole with a project's lines in them |
| `audio.py` | waveform peaks (numpy when installed), sample-exact slicing of one song into pieces, and the built-in silence a replacement can play instead of a file |
| `render.py` | renders segments and whole cues the way the game plays them (exports, Play through); needs numpy |
| `editor.py`, `server.py` | the editor session (autosave and save on demand, undo/redo, the project's list of what it works on, album fill, slicing into chosen slots, patch import, repatching, background builds) and its token-protected localhost API |
| `notes.py` | the notes people write on what the Audio Editor shows: the global ones, for every project, in `notes.json` beside `settings.json`, and the keys both they and a project's (`Project.notes`) go by. A note whose thing a game update took away stays in the file |
| `updates.py` | Audiodiver's own releases on its GitHub repository, for the app's Updates tab (the `releases` method; it only reads, the shell installs). `AUDIODIVER_RELEASES` names a file in the GitHub API's format to read instead (development, tests) |
